# Chính sách bảo mật

Tiếng Việt | [English](#security-policy)

## Báo lỗi bảo mật

Gửi email tới support@sepay.vn, tiêu đề `Security: sepay skill`. Không mở issue công khai.

## Phiên bản được hỗ trợ

Phiên bản theo semver, ghi ở `.claude-plugin/plugin.json` và `metadata.version` trong `skills/sepay/SKILL.md`; thay đổi từng bản ở [CHANGELOG.md](CHANGELOG.md). Chỉ bản mới nhất được sửa lỗi bảo mật. Cập nhật theo cách đã cài: plugin Claude Code `claude plugin update sepay`, `npx skills update sepay`, hoặc tải lại `sepay.zip` / `sepay.md` từ trang Releases.

# Security policy

[Tiếng Việt](#chính-sách-bảo-mật) | English

## Reporting a vulnerability

Email support@sepay.vn with the subject `Security: sepay skill`. Do not open a public issue.

## Supported versions

Versions follow semver and live in `.claude-plugin/plugin.json` and `metadata.version` of `skills/sepay/SKILL.md`; each release's changes are in [CHANGELOG.md](CHANGELOG.md). Only the latest version receives security fixes. Update the way you installed: Claude Code plugin `claude plugin update sepay`, `npx skills update sepay`, or download `sepay.zip` / `sepay.md` again from Releases.
