# Chính sách bảo mật

Tiếng Việt | [English](#security-policy)

## Báo lỗi bảo mật

Gửi email tới support@sepay.vn, tiêu đề `Security: sepay skill`. Không mở issue công khai.

## Phiên bản được hỗ trợ

Repo không chia phiên bản. Chỉ bản mới nhất trên nhánh `main` được sửa lỗi bảo mật; cập nhật bằng `npx skills update sepay`.

# Security policy

[Tiếng Việt](#chính-sách-bảo-mật) | English

## Reporting a vulnerability

Email support@sepay.vn with the subject `Security: sepay skill`. Do not open a public issue.

## Supported versions

The repository has no versions. Only the latest state of `main` receives security fixes; update with `npx skills update sepay`.
